***以德國慕尼黑工業大學（TUM）2025 夏季學期交換經驗為例｜2025 最新***

當初申請上交換生那一刻真的讓人興奮，但沒想到真正的挑戰，其實是從「錄取之後」才正式開始。

以我這次到德國慕尼黑工業大學（TUM）交換為例，在通過台大校內初選後，接下來會是一段漫長的等待期。德國的大學大約要等到當年十月初，國際處才會正式把學生名單提名給德國的姊妹校，所以這段期間還不需要急著準備文件。

但一旦進入十月、收到德方學校確認提名的通知後，一連串要準備的事項就開始陸續登場了。包括上傳申請文件、註冊、簽證辦理、宿舍申請、保險選擇、訂機票等等。德國的流程偏繁瑣，有些步驟還得提早卡位，錯過就會手忙腳亂，像是簽證不能太晚申請、保險需要提早決定等等。

當時我也是上網查了各種資料、翻了很多經驗文，才一步步摸清整個流程，卻**總覺得資訊很零散**。為了幫助即將前往德國交換的你**不走冤枉路**，我將整個流程依照時間順序整理成一系列的文章，總共分為五篇：

## 🗓 我的行前準備時程總覽（僅供參考）

> 以下是我從台大初選通過後，一直到實際出發前的完整準備時程。TUM 的開學日是 4/1，大多數同學會選擇在 3 月底或 4 月初啟程。我的出發時間比較特別，因為我選擇提前幾個禮拜先到歐洲旅行（3/10 出發），不過整體流程與順序對大多數人都仍具有參考價值。

### 📍提名與申請階段（2024/10 月起）

10 月這個階段，台大會完成對姊妹校的提名，接下來的流程就會依各校的交換申請方式而有所不同。以下以我當年度申請 TUM 的時程為例。

| 日期       | 事件                                   | 備註                         |
| -------- | ------------------------------------ | -------------------------- |
| 10/4     | 台大國際處完成提名                            | 等待德國學校通知（約兩週內）             |
| 10/7     | 收到 TUM 提名確認信                         | 含線上申請指引，申請截止日為 10/31       |
| 10/21    | 線上完成 TUM 交換申請、下載表單並寄回¹               | 上傳所需文件²、勾選宿舍意願³            |
| 10/22    | 收到申請完成確認信                            | 等待 12 月初的 Admission Letter |
| 10/31    | TUM 交換申請截止日                          |                            |

**註¹**：寄回給 TUM 負責人時，**記得同時 CC 給台大歐洲區的交換負責人**，以便雙方都能掌握你的進度。

**註²**：所需上傳的文件有：履歷、修課計畫、動機信、語言檢定、護照資訊頁、大學成績單、（研究所成績單）、（學位證明）等。 

**註³**：TUM 交換宿舍申請只需在系統中勾選是否需要住宿即可。其他學校的話有些依申請順序分配，建議一開放就儘快完成；若未獲分配宿舍，可至 Facebook 相關社團查看（例如：慕尼黑台灣同學會、台灣歐洲交換學生群組），須特別留意詐騙風險。

### 📍辦理簽證與註冊階段（2024/12 月起）

進入 12 月後，會陸續收到入學許可（Admission Letter），也就是正式開始辦理簽證與學籍註冊的時候。這段期間的任務較為密集，建議可以把事情區分為三個方向：

1️⃣ 簽證（預約時段、填申請單、準備資料） 👉 [德國交換學生簽證全攻略｜所需文件＋辦理流程一次看懂](/posts/germany-exchange-student-visa-application-guide/)  
2️⃣ 學籍註冊（繳交學期費）  
3️⃣ 限制提領帳戶與保險（Expatrio 留德大禮包） <!--👉 [Expatrio 留德大禮包-限制提領帳戶和保險申請教學](Expatrio%20留德大禮包-限制提領帳戶和保險申請教學.md) #TODO-->  

| 日期      | 事件                                 | 備註                     |
| ------- | ---------------------------------- | ---------------------- |
| 12/2    | 收到入學許可（Admission Letter）           | 含註冊流程說明¹，註冊截止日為 1/10   |
| 12/2    | 台大交換工作坊                            | 行前說明會與學長姐分享交流          |
| 12/6    | 簽證預約成功（德協：1/13）                    | 預約開學前三個月內時段²           |
| 12/19   | 申請 Expatrio 留德大禮包                  | 含限制提領帳戶與保險             |
| 12/20   | 繳交學期費³（Semester Fee）               |                        |
| 12/23   | 匯款至限制提領帳戶                          | 含每月生活費 €992            |
| 12/23   | Expatrio 入帳確認，取得 06 文件             | 作為簽證財力證明               |
| 12/25   | 上傳證件照至 TUMonline                   |                        |
| 1/10    | TUM 註冊截止日                          |                        |
| 1/13    | 前往德協辦理簽證                           |                        |
| 1/14    | 收到註冊確認信⁴（Confirmation Email）       |                        |
| 1/20    | 收到簽證                               | 僅用時一週，效率意外地高           |
| 1/21    | 訂機票⁵                               | 查詢學生優惠、用 Skyscanner 比價 |

**註¹**：收到 Admission Letter 後，**轉寄一份給台大歐洲區負責人**。接著要完成以下三件事：  
- 繳交學期費 €85（繳完後可至 TUMonline 查詢是否入帳）
- 上傳德國健保證明（若使用 Expatrio，系統會自動通知校方，無需手動上傳）
- 上傳證件照至 TUMonline

完成後不會收到確認信，需等待截止日後的註冊確認信（Confirmation Email）。

**註²**：德協的簽證預約需在「開學前三個月內」才能辦理。以我為例，4/1 開學，最早可預約 1/1 的時段。12 月初即可開始預約。我原本與其他申請到 TUM 的同學去信預約團體時段，但德協回覆「今年不開放團體申請」，所以改為個人預約。***（更新：2025 年 2 月起無需搶預約，請 [參考這篇](/posts/germany-exchange-student-visa-application-guide/)）***

**註³**：銀行電匯手續費高，用永豐銀行匯款手續費 NT$1,350，匯小金額很不划算。請在德國交換的同學協助轉帳是最理想的方式。我請在德國交換的學姊用 Revolut 幫我轉帳，並註明我的學號（Matrikelnummer）。 

**註⁴**：收到註冊確認信後，可啟用更多 TUMonline 功能，並取得 TUM ID。可至：`TUMonline → Admission → Documents` 下載 Certificate of Enrollment（註冊證明）。另外，選課可以等三月底再處理。 <!--👉 [交換生到德國後要做什麼](交換生到德國後要做什麼.md) #TODO-->

**註⁵**：一收到入學許可即可考慮訂機票，但我選擇在收到簽證後才購票，較保險。

### 📍宿舍繳費與 Revolut 網銀申辦（2025/2 月起）

在完成註冊與簽證之後，接下來進入了出發前的倒數階段。這段時間會陸續收到宿舍配房通知，確認房租、押金；同時拿到德國地址後也可以開始準備網路銀行（如 Revolut）等生活必備工具。以下是我在 2 月到 3 月出發前實際處理的事項與時程。

| 日期     | 事件                                   | 備註                          |
| ------ | ------------------------------------ | --------------------------- |
| 1/17   | 收到宿舍房間確認信¹                           | 尚未確定租金與地址                   |
| 2/6    | 辦理役男出國申請                             | 出發前 30～60 天提出，依學校信件說明辦理     |
| 2/12   | 收到 Accommodation Offer               | 確定租金²、一週內繳費並回傳簽名文件          |
| 2/17   | 匯款宿舍費、回傳簽名檔與電匯證明                     | 全額到帳                        |
| 2/18   | 宿舍方確認入帳                              |                             |
| 2/20   | 收到 Tenancy Agreement                 | 含正式地址、需簽名回傳                 |
| 2/22   | 開戶 Revolut 網銀³                       | 有簽證與德國地址後可申請                |
| 2/27   | 宿舍方回傳簽署完成的 Tenancy Agreement         | 領鑰匙時需出示                     |
| 2/28   | 線上申請杜拜轉機簽證⁴                          | 最快當天核發，費用 $24.92 USD        |
| 3/9    | 線上預約德國入籍 Termin（預約 4/8）              | 亦可等入住宿舍前一兩週再預約⁵             |
| 3/10   | ✈️ 出發前往德國                            | 我的交換之旅正式開始！                 |

**註¹**：宿舍確認信中不一定會附詳細房型資訊。我是直到實際入住才知道房型。以我為例，是 8 人 WG（共用廚房）、獨立衛浴，房內有床、床墊、桌椅、衣櫃。Service Package 會提供睡袋、枕頭、枕頭套、床單。房內僅提供乙太網路孔，建議自備網路線和 Wi‑Fi 路由器。 👉 [交換行李清單](/posts/exchange-student-survival-guide-2-packing-list/)

**註²**：我的房租為 €391.5，押金 €430，需一次繳交 3 個月月租 + 押金，共 €1604.5。

**註³**：Revolut 可作為德國常用數位銀行，開戶需完成視訊驗證並提供德國地址與有效簽證。 <!--👉 [Revolut 開戶流程與心得](Revolut%20開戶流程與心得.md) #TODO-->

**註⁴**：我搭乘阿聯酋航空，在杜拜轉機約 10 小時。若想在轉機期間入境觀光，可於出發前一個月內透過航空公司網站申請 48 小時過境簽證。我當天申請當天就核發，費用 $24.92 USD。詳細申請教學可參考：[這篇文章](https://medium.com/im-off-then/%E6%9D%9C%E6%8B%9C-2023-%E9%80%8F%E9%81%8E%E9%98%BF%E8%81%AF%E9%85%8B%E8%88%AA%E7%A9%BA-emirates-%E7%B7%9A%E4%B8%8A%E7%94%B3%E8%AB%8B%E6%9D%9C%E6%8B%9C%E7%B0%BD%E8%AD%89-f4a1ea118403)。

**註⁵**：德國規定需於抵達後兩週內完成入籍（Anmeldung），但實際上需入住後才能取得的「居住提供證明（Wohnungsgeberbestätigung）」，而非 Tenancy Agreement。若像我提前抵達，而租約是 4/1 才開始，就無法立即完成入籍，不過實際上似乎也不會被罰。因釋出名額有限，建議可於入住宿舍前一兩週先線上刷預約時段。 <!--👉 [交換生到德國後要做什麼](交換生到德國後要做什麼.md) #TODO-->

## 📎 其他提醒（Fraenk 網路、電信門號推薦）

在國外的網路真的很重要。我當初是先購買歐洲旅遊用的 eSIM，抵達德國後才辦當地電信門號。不過後來發現，只要有 **Revolut** 帳戶，其實可以直接申請德國本地的電信方案，所以（應該）出發前就可以申請。

我推薦使用 **Fraenk**，這是一款方便又價格實惠的德國電信服務，只要下載 App 即可申辦，不需要跑門市，流程簡單、全程線上完成：

- 需從 **德國 App Store** 下載 Fraenk App（建議申請一個德國 Apple ID，也可以切換區域）
- 雖然介面為德文，但操作流程直覺，照著網路上教學走即可完成。
- Fraenk 支援 **歐洲大部分地區的漫遊使用**，對於像我這種把交換當成旅遊跳板的學生來說，非常友善 XD。

💡 註冊時輸入我的推薦碼：**YUNF5**，我們雙方每月都可以額外獲得 **5GB 流量**，非常划算！

最後還有一些零散但實用的小事項，也建議一併事先處理，才不會臨時手忙腳亂：

- **準備國際信用卡**（建議使用雙幣卡）
- **換好一些歐元現金**（建議準備至少 €300，到當地拿到 Revolut 實體卡後可再提領）
- **辦理國際駕照**（若有計畫在歐洲自駕旅行的話）

這些雖然不是申請流程的「主線任務」，但都能讓你的交換之旅更順利、更安心！
